# LA32R-Core

## 简介

根据[《CPU设计实战：LoongArch版》](https://bookdown.org/loongson/_book3/)开发

参考 [openLA500](https://gitee.com/loongson-edu/open-la500) 的乘法器、除法器实现

使用 [chiplab](https://gitee.com/loongson-edu/chiplab) 框架和 AMD Vivado™ Design Suite 2023.2 进行仿真

## 分支

master: 仅支持基本指令，可通过 chiplab 框架截至 exp19 实验的 n1 ~ n72 测试

chiplab: 支持全部指令，但无 cache 集成，可通过 chiplab 框架所有实验的 n1 ~ n81 所有测试

cache: WIP

其它: 《CPU设计实战：LoongArch版》所述实验的阶段性归档
